# Cutline

A fast, offline video editor for Windows 10/11, made for editing gameplay recordings: 1440p and
ultrawide footage at 60 fps, game and mic audio on separate tracks. Premiere-style layout and
shortcuts, GPU decoding and export, and no internet connection needed.

## Install

1. Go to **[Releases → latest](https://github.com/CainanNevils/cutline-releases/releases/latest)**
   and download `Cutline-<version>-win64.zip`.
2. Unzip it and double-click **`Install.cmd`**.
   Windows may show "Windows protected your PC" because the app isn't code-signed:
   click **More info → Run anyway** (first install only).
3. Cutline opens and adds Desktop and Start Menu shortcuts. No admin rights needed.

Press **F1** in Cutline for the full guide (features and keyboard shortcuts).

Needs a DirectX 11 graphics card; an NVIDIA card gives the fastest exports.

## Updates

Download the newer zip from Releases, unzip it and double-click `Install.cmd` again. It replaces
the old version; your projects and settings are kept. (Close Cutline first.)

## Uninstall

Settings → Apps → Cutline → Uninstall. Your projects and settings are kept.
